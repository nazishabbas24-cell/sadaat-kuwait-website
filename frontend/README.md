# Frontend - صدات الكويت

Next.js 14+ React application for Sadaat Al Kuwait electronics shop website.

## الميزات

- ✅ تصميم متجاوب الحجم (Mobile-First)
- ✅ واجهة ثنائية اللغة (العربية - اليمين لليسار)
- ✅ تصميم حديث باستخدام Tailwind CSS
- ✅ آمن النوع مع TypeScript
- ✅ أداء عالي مع Next.js 14

## البدء السريع

```bash
npm install
npm run dev
```

ثم افتح [http://localhost:3000](http://localhost:3000)

## البنية

```
src/
├── app/          # صفحات التطبيق
├── components/   # المكونات القابلة لإعادة الاستخدام
├── styles/       # الأنماط العامة
└── utils/        # دوال مساعدة
```
