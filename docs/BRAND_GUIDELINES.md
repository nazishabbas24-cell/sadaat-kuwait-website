# Sadaat Al Kuwait - Brand Guidelines

## Color Palette

### Primary Colors
- **Trust Blue**: `#0056B3` - Used for CTAs, headers, and trust elements
- **Pure White**: `#FFFFFF` - Background and clean spaces
- **Tech Silver**: `#6C757D` - Accents and secondary elements

### Secondary Colors
- **Success Green**: `#28A745` - For positive messages (repair complete, in stock)
- **Warning Orange**: `#FFC107` - For alerts and important notices
- **Danger Red**: `#DC3545` - For out of stock, errors

## Typography

### Font Stack
- **Arabic (Primary)**: Cairo, Arial, sans-serif
- **English (Secondary)**: Inter, -apple-system, BlinkMacSystemFont, Segoe UI, Roboto, sans-serif

### Hierarchy
- **H1**: 48px (desktop), 32px (mobile) - Hero titles
- **H2**: 32px (desktop), 24px (mobile) - Section headers
- **H3**: 24px (desktop), 20px (mobile) - Subsection headers
- **Body**: 16px - Standard text
- **Small**: 14px - Secondary text

## Tone of Voice

✅ **Do:**
- Be professional and trustworthy
- Use local references (Kuwait, neighborhoods)
- Emphasize expertise and certification
- Be friendly and customer-focused
- Use clear, simple language

❌ **Don't:**
- Use overly casual language
- Make technical jargon complicated
- Overpromise on repair times
- Use bright, unprofessional colors

## Visual Elements

### Icons
- Use line-based icons (Feather, Font Awesome) for consistency
- Ensure 24px minimum size for mobile
- Maintain 2px stroke weight

### Images
- High-quality product photography
- Real team photos (builds trust)
- Consistent lighting and composition
- Optimized for web (WebP format preferred)

### Spacing
- Use 8px grid system for consistency
- Mobile: 16px padding
- Desktop: 24px padding
- Section gaps: 48px-64px

## Logo Usage

- Logo minimum size: 48px
- Always maintain clear space (1x logo height)
- Never distort or rotate
- Use primary blue on white background

## UI Components

### Buttons

**Primary CTA** (Book Repair, Shop Now)
```
Background: #0056B3
Text: White
Padding: 12px 24px
Border-radius: 6px
Font-weight: 600
Hover: #004085
```

**Secondary Button** (Learn More, Filter)
```
Background: Transparent
Border: 2px solid #0056B3
Text: #0056B3
Hover: Light blue background
```

### Cards
- Border-radius: 8px
- Box-shadow: 0 2px 8px rgba(0,0,0,0.1)
- Padding: 16px-24px
- Hover: Slight lift (shadow increase)

## RTL/LTR Implementation

- All text is automatically flipped based on language
- Icons remain consistent regardless of direction
- Padding/margin follow standard RTL rules
- Forms adjust for right-to-left input

## Accessibility

- Minimum contrast ratio: 4.5:1 for text
- All interactive elements: 48px minimum touch target
- ARIA labels for screen readers
- Keyboard navigation support
